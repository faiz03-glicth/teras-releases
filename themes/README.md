# Themes

Festive themes designed for Teras but not in the app yet. Each board shows the same 15 screens in the theme: Home, this week's muscles, a workout, the saved workout, share pictures, Profile, the calendar, logging a past workout, and picking the theme on Profile.

The themes already in the app (Misery, Spidey, Winter, Rain and Into It) are picked from the theme wheel on Profile.
